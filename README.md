# Student Finance Management System

## Introduction

Student Finance Management System is a Python-based application designed to help students manage their personal finances.

The system allows students to record income and expenses, set monthly budgets, monitor their balance, search transactions and analyze their spending habits.

---

## Objectives

The main objectives of this project are:

- To maintain student income records
- To record daily expenses
- To categorize expenses
- To calculate the current balance
- To set and monitor a monthly budget
- To analyze spending patterns
- To store financial data permanently
- To provide a simple and user-friendly finance management system

---

## Features

### 1. Add Income

Users can add income such as:

- Monthly allowance
- Scholarship
- Part-time income
- Freelance income
- Other sources

### 2. Add Expense

Users can record expenses under categories such as:

- Food
- Transport
- Education
- Shopping
- Entertainment
- Accommodation
- Recharge
- Other

### 3. View Transactions

Users can view all recorded income and expenses.

### 4. Balance Calculation

The system calculates:

Total Balance = Total Income - Total Expenses

### 5. Monthly Budget

Users can set a monthly spending budget.

The system displays warnings when the user reaches:

- 80% of the budget
- 100% of the budget

### 6. Financial Summary

The system provides:

- Total income
- Total expenses
- Remaining balance
- Category-wise expenses
- Highest spending category
- Highest individual expense
- Average expense
- Savings percentage

### 7. Search Transactions

Users can search transactions using:

- Category
- Description
- Date

### 8. Monthly Analysis

Users can analyze expenses for a particular month.

### 9. Delete Transactions

Users can remove incorrect or unwanted transactions.

### 10. Data Storage

Financial information is stored in a JSON file so that the data remains available after closing the program.
